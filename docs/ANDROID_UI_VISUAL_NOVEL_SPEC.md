# ANDROID_UI_VISUAL_NOVEL_SPEC：安卓端"视觉小说"式伴侣界面

> 来源：`docs/newly_added/design_append.md`（2026-08-29 UI 设计稿）的深入扩展与落地裁决。
> 目标：在"单张静态立绘、无表情差分、纯文字+图像交互"的约束下，用 **UI 动效 + 环境反馈 + 情绪数据面** 弥补角色表情缺失，把安卓端从 IM 列表升级为沉浸式陪伴界面。
> 上位文档：`DESIGN.md` §9/§10；现有实现基线：`Theme.kt`（Claude 奶油色板，commit 913d0ee）、`MainActivity.kt`、`bridge.py`。
> 红线：不改 `render_im` 防泄漏出口；所有可调配置进设置页（用户偏好）。
> 依赖策略（2026-08-29 用户修订）：底层支持且能提升 UI 表现即可引入 Gradle 依赖——本次定 **Coil**（异步图片加载/内存缓存）与 **Haze**（面板真 backdrop 模糊）。chaquopy pip 白名单不变：UI 渲染全在 Kotlin 侧，Python 只是数据源，无新增 pip 需求。

## 1. 设计稿逐条裁决

| # | 原稿条目 | 裁决 | 说明 |
|---|---|---|---|
| 1 | 全屏视觉小说布局（立绘 60-70% + 毛玻璃对话面板） | ✅ 采纳，**变体** | 纯 VN 单行对话框会杀死历史浏览（历史持久化+图片渲染是已验收功能，不可回退）→ 做**混合架构**：面板收起=VN 舞台（最新一轮对话），面板上滑展开=现有 IM 历史列表（气泡+图片原样保留）。MotionLayout 不用——项目已是 Compose，`infiniteTransition` 即可，少一层概念 |
| 2 | 情感化文本渲染（关键词变色 + 打字机） | ✅ 采纳，**变体** | 打字机全做（自适应速度）。"关键词级变色"降级为**段落级**：词级情绪标注需要额外逐词分析，不稳定且贵；段落级由情绪标签 + 环境光承载同等信息量，成本差一个数量级 |
| 3 | 背景环境光效（情绪/图片色彩 → 背景径向渐变，不碰立绘颜色） | ✅ 采纳 | 情绪→预设渐变表；用户图片→位图降采样取主色（Bitmap 缩到 16×16 求均值，纯 SDK，无 Palette 依赖）。光效只画在立绘**后面的背景层** |
| 4 | 输入区（文本+发送+附件） | ✅ 采纳 | 现有输入栏已满足三元素，保留；拍立得预览=重排现有 `pendingImages` 文件名行为缩略图卡片；触感反馈=`performHapticFeedback`，可配置开关 |
| 5 | 状态指示器 | ⚠️ 部分采纳 | **思考粒子保留**：每轮回复有真实 1~2s LLM 延迟，"正在酝酿…"有信息量。**聆听光晕删除**（2026-08-29 用户裁决）：无 STT 时输入焦点+键盘已是完整的"等待输入"信号，呼吸描边是冗余装饰。**空闲屏保砍掉**（用户裁决：暂不必要）。 |
| 6 | 马卡龙色 + 夜间模式 | ✅ 采纳，**变体** | 现有奶油底 `#FAF9F5` 本身就是马卡龙"米白"，保留为日间基底（不推翻 913d0ee，只在其上扩展）；珊瑚色保留给发送钮。夜间=跟随系统深色主题，画布转藏青 `#16161d`，毛玻璃不透明度提高。不做独立手动开关（跟随系统=少一个设置项） |
| 7 | 文本情绪标签（💭 温柔 等小圆角标签） | ✅ 采纳 | 依赖数据面 §2.2（逐条回复的 tone）。主动消息无 tone 时回退 mood 三档映射，保证标签永不为空也不造假 |

**非目标**（明确不做）：表情差分（无美术资产）；词级情绪高亮；MotionLayout；图片加载库（Coil/Glide——现有 BitmapFactory 降采样已验收）；立绘本身变色/加滤镜。

## 2. 数据面契约（bridge / core 改动）

### 2.1 立绘入包与分发

- `android/fuyuno/app/src/main/assets/portraits/lin.jpg` ← 构建期从 `characters/lin/portraits/lin_halfbody.jpg` 拷入（`tools/sync_assets.py`，一个 shutil.copy 脚本，gen_config 同目录同风格）。
- `bridge.portrait_path() -> str`：boot 时把 assets 立绘解到 `filesDir/portraits/<char>.jpg`（已存在且同大小则跳过），返回绝对路径；角色卡有真实差分图时（未来）优先用角色目录的图。**无图返回空串，UI 回退纯色舞台**——长宽比兜底不依赖立绘存在。

### 2.2 逐条回复情绪（tone）——轻量分类调用

遵循既定判断点哲学（质量敏感的语义判断=每处一次低成本 LLM 调用，失败回退规则）：

- `agent.handle(channel="im")` 成功生成回复后，追加一次分类调用：
  - 输入：本轮回复文本（截断 300 字）+ 角色卡 `tones` 词表；
  - 输出：单 JSON `{"tone": "<词表内一词>"}`，`max_tokens=64`，`timeout≤8s`；
  - 失败/超时/词表外 → `tone=""`，UI 回退 `mood_at` 三档。**绝不阻塞主回复返回**（主文本先回，分类结果随返回体带出；分类在回复落库前完成，总延迟预算 +1~2s）。
- `messages` 表加列 `tone_at TEXT NOT NULL DEFAULT ''`（migrate，同 attachments 先例）；assistant 消息落库时写入；主动消息（`record_proactive_message`）写 `""`。
- 配置：`ui.emotion_tags: true`（默认开——用户哲学偏好 LLM 判断；成本：每轮回复 +1 次 ~60 token 调用）。设置页可关。

### 2.3 接口出参扩展

- `bridge.chat()` 返回增加 `"tone"`（本轮分类结果）。
- `bridge.history()` 每条消息增加 `"mood"`（`mood_at`）、`"tone"`（`tone_at`）；user 消息两者为空。
- `bridge.ambient_seed(image_path) -> "#rrggbb" | ""`：用户发图时的主色提取（16×16 降采样均值），随 `chat()` 返回 `"ambient"` 键。仅当 `ui.ambient_light` 开且本轮带图时计算。
- `bridge.idle_config() -> str`：把 `ui.*` 配置打包给 Kotlin（避免每个键一个 callAttr）。

## 3. 表现层：舞台架构

### 3.1 层序与布局（竖屏，任意长宽比）

```
┌─────────────────────────────┐
│ L0 环境光背景（全屏径向渐变）   │  ← mood/tone/图片主色驱动
│ L1 立绘（宽适配，顶对齐）      │  ← 底部渐变遮罩融入背景
│ L2 状态指示（光晕/粒子）       │
├─────────────────────────────┤
│ L3 毛玻璃对话面板（40% 屏高）   │  ← 可拖拽：收起=最新一轮 / 展开=全历史（封顶 70%）
│    └ 输入栏（现有三元素）      │
└─────────────────────────────┘
```

- **长宽比适配**（用户裁决的核心诉求）：立绘按**宽度适配**（宽=屏宽×0.86，黄金分割偏右居中），超高屏顶部留白给环境光，超矮屏立绘被面板自然遮脚部（渐变遮罩本来就是融合用的）——任何比例都不裁脸。无立绘时 L1 整层不渲染，L0 渐变全屏，布局零分支。
- **毛玻璃**：采纳 **Haze**（dev.chrisbanes.haze）——API 31+ 面板对底下立绘做真 backdrop 模糊，<31 自动降级 92% 不透明+发丝边。MuMu API 32、真机 API 36，真模糊可用。
- **立绘随面板联动上移（2026-08-29 用户追加）**：舞台区 bottom padding 绑定 `panelH` 同步动画——展开时立绘整体上移，`ContentScale.Fit` 在剩余可见区内自动缩放，永不被面板遮挡；展开面板封顶 70% 屏高，给立绘留头部空间。
- 面板拖拽：Compose `anchoredDraggable`（或 `swipeable`）两档锚点，速度/位移阈值取默认值。

### 3.2 对话面板两态

| 态 | 内容 | 触发 |
|---|---|---|
| 收起（默认） | 角色名（衬线小标）+ **最新一条回复全文**（打字机）+ 最新一条用户消息摘要一行；情绪标签圆角小徽章 | 默认；展开后下滑 |
| 展开 | 现有 IM 历史列表**原样**（深色/奶油气泡、图片缩略图、点击放大） | 上滑面板 / 点击收起态文本区 |

历史图片渲染、`[图片]` 占位剥离、重启持久化等已验收行为在展开态完整保留——这是不可回退项。

### 3.3 动效参数表（全部 Compose `infiniteTransition`，无第三方库）

| 动效 | 参数 | 备注 |
|---|---|---|
| 立绘呼吸 | translateY ±3dp，2.8s，FastOutSlowIn 往返 | 单层立绘的"活感"主力 |
| 打字机 | 每字 `clamp(总时长=字数×38ms, 1.2s, 5.5s)`；标点停顿 ×1.8 | 长回复自动加速，不拖沓 |
| 思考粒子 | 3 粒子上抛 8dp 错峰 0.25s + "正在酝酿…" | 替代 CircularProgressIndicator |
| 面板态立绘联动 | 舞台区 padding 跟随 `panelH` 260ms | 立绘永不被遮挡 |
| 情绪标签入场 | α 0→1 + 上移 4dp，220ms | 随回复到达 |
| 系统动画缩放 | 全部乘 `Settings.Global.ANIMATOR_DURATION_SCALE` | =0 时静态呈现，无障碍 |

### 3.4 情绪 → 视觉映射表

**Tier 1（无分类结果，回退 mood）**：

| mood | 标签 | 环境光渐变（中心→边缘） |
|---|---|---|
| 开心 | ✨ 心情不错 | 香槟金 `#f3e2c7` → 奶油 |
| 平静 | 💭 平静 | 米白 `#faf9f5` → 暖灰 |
| 低落 | 🌧 有点闷 | 雾蓝灰 `#c9cdd6` → 暖灰 |

**Tier 2（tone 分类命中，19 词表 → 6 组氛围）**：

| 氛围组 | tone 成员 | 标签样式 | 环境光 |
|---|---|---|---|
| 暖 | 喜悦/微笑/温柔/暧昧 | 暖橙字 `#c77b4a` | 淡粉 → 暖黄 |
| 静 | 闲置/安静/认真/恭敬 | 墨色细体 | 米白 → 暖灰 |
| 锐 | 毒舌/戏谑/调侃/不屑 | 珊瑚加粗 | 浅珊瑚晕边 |
| 沉 | 失落/悲伤 | 雾蓝细体 | 深蓝灰 → 紫灰 |
| 动 | 好奇/惊讶/愤怒/严肃 | 墨色正常 | 暖灰微升 |
| 夜（仅 23:00-6:00 叠加） | 任意 | 标签 α 降至 70% | 藏青 `#1b1e2b` → 深紫灰 |

**图片主色叠加**：用户发图且 `ambient` 命中时，环境光边缘色混入主色（权重 30%），一轮后随下一条回复自然消退（1.2s 渐变过渡，不闪跳）。

### 3.5 夜间模式

跟随系统 `isSystemInDarkTheme()`：画布 `#16161d`、面板 `#1f1f27`（毛玻璃 α 96%）、文字 `#e8e6e0`、环境光表整体降明度 40%。色板收口仍在 `Theme.kt`（新增 `darkColorScheme`），不另起文件。

## 4. 输入区增强（现有三元素之上）

- **拍立得预览**：待发送图片显示为 56dp 缩略图卡片（白边 2dp + 随机 ±3° 旋转 + 轻阴影），横向排列于输入栏上方；点卡片可移除该图（现有"重选覆盖"逻辑保留）。
- **图片气泡尺寸**：展开态图片 `宽度 = 屏宽 × 0.6`（现为固定 220dp），圆角 12dp。
- **点击放大**：全屏 Dialog 显示原图，黑色背景 α 92%，点击任意处关闭。捏合缩放不做（无依赖前提下收益低）。
- **触感反馈**：发送成功、收到回复、面板锚点吸附各一次 `HapticFeedbackConstants.KEYBOARD_TAP`；配置 `ui.haptics: true`。

### 4.5 设置页风格一致性（2026-08-29 用户追加）

设置页 = 聊天页的简化版：同奶油画布、同衬线页头（「设置」大字）、分区收进 `surface-card` 卡片（hairline 边、圆角 12、无阴影）；
移除 `TopAppBar` 默认灰底；珊瑚色只保留给「重启生效」这类确认动作主按钮；输入框焦点环继承 coral（色板源仍唯一：`Theme.kt`）。

## 7. 验收纪律（行为级，防 grep 式假验收）

- tone 分类：真远程 API 连续 10 轮，检查 `tone_at` 非空率、词表外回退、超时不阻塞主回复；
- 环境光/标签：UI 截图 + vision_analyze 双证据；
- 打字机/思考粒子/立绘联动：定时截图序列；
- 历史功能回归：重启后历史+图片+展开态渲染不回退；
- 所有 `ui.*` 开关在设置页切换后即时生效（重启生效项需标注）。
