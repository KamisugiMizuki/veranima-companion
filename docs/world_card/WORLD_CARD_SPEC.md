## 0. 设计结论

**一句话**：世界卡是一张可独立设计、可分发、可校验的"世界"资产——角色卡定义她是谁，世界卡定义她活在哪儿；全量条目供生成 / 校验 / 追问，运行切片喂消费端。

**三个验收面**：

1. 被追问不打架——不变式 I1–I6（继承）＋ T1–T4（体裁扩展，§4）；
2. 表达不穿帮——语汇映射与规则边界（§2.6 / §2.3）在长对话里持续生效；
3. 可生产、可校验——生成器与校验器闭环，没有一条素材会被用户抓住现编（§6）。

**形态（D1–D4）**：世界是自足的共享舞台——独立世界钟（D1）、世界事件引擎（D2）、实情 / 公共叙事双轨（D3）、多角色共享（D4）；世界自行运转，角色是同一舞台上各自生活的住户。

**体裁目标**：以异世界（fantasy）为第一体裁；结构体裁无关，科幻等按同一体系换参数（承接 VSP D7）。

## 1. 定位与分账

### 1.1 三件财产

| 财产 | 归属 | 说明 |
|---|---|---|
| 条目体系 / 卡格式 / 生成器 / 校验器 | 世界卡项目（待建） | "世界怎么被设计出来" |
| 运行切片：加载合并 / 通行流量 / 表达注入 | veranima（VSP W 线照旧） | "世界怎么被运行时消费" |
| 某个具体世界的条目内容 | 卡数据 | 不是规范 |

### 1.2 继承的四条原则

1. **引擎与体裁无关**（VSP D7）——异世界不是另立格式，是同一张卡的另一套体裁参数；
2. **厚数据薄引擎**——卡可以全量，运行期只消费薄切片；
3. **世界=数据面 / 角色=表达面**——世界不被看见，只通过她与氛围被感知；
4. **fail-open**——条目缺失按缺省退化，不阻断任何链路。

### 1.3 四条消费面（条目取舍纪律）

条目量可以大，但**每条至少要指认一个消费方**；指认不出消费方的条目放附属文本区（不参与链路），不进结构化卡：

| 消费面 | 形态 | 例 |
|---|---|---|
| 运行时真值 | 程序读：结构化、可校验 | 时间换算表、地理切片 |
| 生成期素材 | 生成器 / 命名库读 | 音韵规则、地名池 |
| 表达约束 | 进 prompt 组装 | 禁词表、概念映射 |
| 追问弹药 | 被问到时有据可答 | 年表、物价锚点、天象函数 |

### 1.4 与 veranima 世界文件的关系

`virtual_world.json`（VSP §5.6）是**运行切片的实现格式**；世界卡是它的上一级——全量条目 ＋ 切片投影规则。**地理层单源沿用 VSP 格式，不出现第二份地理规范**。

### 1.5 非目标（v0.2 明写不做）

- 生成算法与工具的实现（新项目成立后另立）；
- 卡编辑器 / 可视化；
- 世界事件引擎与多角色共享的**实现**（方向已定，见 §2.8 / §1.6；分期另立）；
- 任何具体世界的内容。

### 1.6 共享性（D4=B：一张卡承载多角色）

- **世界级真值单源**：时间、事件、地理、气候——同一世界所有角色共用同一份；
- **角色级内容仍归角色资产**：她的家（锚点）、日程、关系、记忆——按既有隔离裁决（协调对象：`MOMENTS_MULTIROLE_SPEC` 的 Q1 折中隔离）；
- **生成与校验按多角色设计**：生成器输入含多张角色卡的锚点集；校验器验多角色并存一致性（锚点共存、可达、事件事实一致）；
- VSP §4.2 的"跨角色共享另立规范"缺口——本规范即该"另立"的世界侧起点；运行侧共享规则仍待协调。

## 2. 条目体系（八层 ＋ 工具层）

内容条目八层（§2.1–§2.8），工具层单列（§2.9）。**"不穿帮四件套"**（时间 / 历法、语汇映射、命名库、规则边界）为最小可用集；其余层是追问深度与生活质感的加码，可分批长出来。

### 2.1 天体与宇宙

- 自转周期（日长）、公转周期（年长）、轴倾角（季节结构）；
- 恒星：数量（单 / 双 / 多）、类型、亮度；可见的其它行星；
- 卫星：数量、周期、月相——直接决定"月"从哪来、夜晚亮度、潮汐；
- 世界形状：球面 / 浮空群岛 / 平面 / 环形——异世界高频设定，决定"地平线""世界尽头"类追问的底；
- 特殊天象：极光 / 流星雨 / 魔力潮汐等。
- 消费面：生成期（常量）＋ 追问（派生函数）＋ 表达·软（夜 / 月 / 季的措辞）。

### 2.2 时间与历法

- 日的切分（小时数、报时习惯）、月份 / 周的来源（卫星周期或人为划分）、纪年；
- 节日表——可与 veranima 既有日型档（holiday_like 等）对接；
- **世界钟**（纪元 / 日长 / 速率）与**消费侧对齐策略**（见 §3）。
- 消费面：运行时（时刻换算）＋ 追问。

### 2.3 规则体系

顶层枚举：`魔力 / 纯物理 / 能量晶体 / 混合 / 卡自定义`（开放性，同 VSP D7 判据）。每类必答子字段：

| 子字段 | 要求 |
|---|---|
| 来源 | 能量从哪来 |
| 习得 | 谁能用、怎么学 |
| **代价** | 用什么换——无代价的体系撑不过第一次追问 |
| **边界** | 做不到什么——必须能解释社会后果（"为什么还有穷人 / 为什么不用它修路"） |
| 普及度 | 全民 / 少数 / 职业化 |
| 可见性 | 日常多常见、街面上看不看得见 |

- 技术水平档 → 日常语汇（灯、通信、出行、医疗靠什么）；
- 她**个人的**能力状况属角色卡，本卡只给规则与普及度（归属表见 §5）。
- 消费面：表达约束 ＋ 追问 ＋ 生成（活动语汇）。

### 2.4 地理

- 已由 VSP v1.2 覆盖（路网 / 线路 / POI / 流量 / 体裁映射表）——**不重造**；
- 世界卡需补：大尺度地名池（大陆 / 国 / 城，含"她只知传闻的远方"）、危险区 / 禁地（活动边界的来源）、气候带与生态。
- 消费面：运行时（切片）＋ 追问。

### 2.5 社会与文明

- 政体、种族、阶层与职业、教育与识字；
- 宗教——誓言 / 感叹 / 节日用语直接进台词；
- 货币与**物价锚点表**（"一碗面多少钱"必须答得出且跨轮稳定）；
- 法律禁忌、衣食住行、称呼体系。
- 消费面：表达 ＋ 追问 ＋ 生成。

### 2.6 语汇与表达约束

- 现代概念 → 世界等价物映射表（手机→？、地铁→？、便利店→？）；反向**禁词表**；
- 度量与时间说法（"公里""小时"能不能用；世界单位与呈现换算）；
- 称呼与语气词、名字的音韵风格。
- 消费面：表达约束（进 prompt 组装）。**对陪伴场景，这是日常收益最大的一层**——天文是追问弹药，它是每天说的话。

### 2.7 历史与神话

- 创世 / 神系 / 年代框架（近百年大事 ＋ 传说层）、地名由来、典故；
- **知识双轨（D3=C）**：公共叙事层（民间说法、信仰、分歧——她的话从此层出）与实情层（创作者真值——供一致性校验与跨角色协调）分开记录；角色能触及哪一层由角色卡声明，不得越层；
- 深度上限：超出层次的追问归"不清楚"——留白是合法状态，现编不是（I6 体裁版）。
- 消费面：追问 ＋ 表达。

### 2.8 当下与事件（世界事件引擎，D2=C）

- 世界级事件：政治 / 灾害 / 节庆 / 风闻——按世界钟推进，供共享世界里的多角色共同参考；
- 生成纪律：确定性种子 ＋ 可复算（沿用 VSP 纯函数纪律：同一世界同一天，任何消费者同答案）；
- 产出＝素材与追问弹药：接入既有素材管道的方式属接缝（不自动广播）；多角色共享时事件是公共事实源，谁知晓什么由消费侧声明；
- 规模提示：这是独立子系统（生成 / 校验 / 可见性），实现另立分期——本规范只定条目与契约位。
- 消费面：追问 ＋ 表达 ＋ 生成。

### 2.9 生产与校验（工具层）

- 命名库、生成器、校验器（机制见 §6）。
- 消费面：工具。

## 3. 时间体系（独立世界钟，D1=C）

**原则：世界钟独立推进。** 世界的时间由卡定义（纪元 / 日长 / 速率），是自足的钟——不假设与现实一天对齐；任何真实时刻的世界时间都是确定性函数，可复算、经得起追问（"同一问题同一答案"照旧）。

- **钟的三参数**：纪元（世界历起点）、日长（一世界日折合多少世界时）、速率（世界时 ÷ 现实时的换算率）——一经声明恒定；
- **世界时刻** ＝ 纪元 ＋ 速率 × 现实流逝；日长 ≠ 24 是常态而非特例；
- **昼夜 / 季节 / 月相 / 节日**：全部挂世界钟（昼夜段、季节表、卫星周期函数、节日表）；
- **对齐策略（消费侧，非卡侧）**：任何消费端都要自行决定如何使用世界时刻——
  - 纯世界消费（模拟 / 创作 / 观察）可保持自由漂移：她的黑夜可能撞上你的白天，这是该形态的已知代价；
  - 需要同步的消费端（如未来的陪伴端）可在消费侧声明对齐策略（例："按日对齐"：取速率 ＝ 日长 ÷ 24 并配相移，让她的活跃窗落进用户昼夜——等价早期方案 A 的行为，但不改变卡的钟）；
- **多角色共享**：同一世界的所有角色共用一个钟，不得按角色各自对时（§1.6）；
- **表达纪律**：她的时间 / 时长 / 数量表述全部从世界钟推导，以世界单位给出、与换算表一致；"多久 / 多远"用模糊说法（沿用 VSP 表达纪律）；"现在几点 / 天黑了没"永远可答。

## 4. 自洽不变式（体裁版）

**继承（VSP §2，I1–I6）**：存在性封闭 / 时空可行 / 节律一致 / 理由可溯 / 描述稳定 / 留白有边界——逐条适用，无需修改。

**体裁扩展（本文新增）**：

| # | 不变式 | 追问出的样子 |
|---|---|---|
| T1 | 天象一致：卫星数 / 月相 / 特殊天象跨轮跨日稳定且可推导 | "你们有几颗月亮？"→ 同一答案；"下次满月？"→ 算得出 |
| T2 | 历法一致：日期 / 节日 / 季节 / 她的话互不打架 | "今天有集市吗？"→ 与世界日期一致 |
| T3 | 能力一致：规则边界稳定，不因叙事方便破例 | "你不是说魔法做不到吗？"→ 无例外；例外必须提前声明且有代价 |
| T4 | 语汇不穿帮：禁词表与概念映射在长对话中持续生效 | 不冒出"手机""公司""APP"；单位换算不自相矛盾 |

> 完整验收集沿用 VSP §15 的探针式验收（I-边界感 / I-背景感 / I-一致感），扩展 T 系列探针。

## 5. 归属边界（世界卡 / 角色卡）

两卡分工必须在**卡制作指南**里写明，防互相推诿、防两面包抄：

| 追问 | 归属 |
|---|---|
| 你会魔法吗 / 你有什么能力 | 角色卡（本卡只给规则与普及度） |
| 你身边都有谁（家人 / 同事） | 角色卡（NPC 名册）；本卡给社会规范与称呼体系 |
| 你们一般怎么过节 | 世界卡 |
| 你的职业 / 每天干什么 | 角色卡 ＋ 日程文件 |
| 一碗面多少钱 | 世界卡（物价锚点） |
| 你住的地方什么样 | 世界卡（地理切片）＋ 角色卡（她的家） |
| 你怎么给我发消息 | 角色卡创作层（维持 VSP D7） |
| 外面（远方 / 外国）现在怎么样 | 世界卡（世界事件引擎，§2.8） |
| 你们有电吗 / 有手机吗 | 世界卡（规则 ＋ 语汇） |

## 6. 生产、校验与分发

- **命名库**：人名 / 地名 / 组织 / 月名 / 货币的构词与音韵规则；生成后人工抽查；
- **生成器**：结构由代码定（沿用 VSP 模式），文本可 LLM 产一次，不通过就手编；产物落盘为卡文件——可手编、可 diff、可导出；
- **校验器**（fail-open 分级）：引用完整性 / 体裁判定（现代词黑名单扫描）/ 换算一致性（时长与单位抽查）/ 多角色并存一致性 / 不变式探针（I 系列 ＋ T 系列）；
- **红线继承**（VSP §10 ＋ D7）：不混入现实专名（地名 / 品牌 / 宗教实体）；`closed` 世界不引现实新闻；用户现实信息不入卡；
- **质量目标**（同 VSP）：不是"像某某作品"，是**没有一条素材会被用户抓住现编**；
- **分发形态**：与角色包的关系待定（§8 D7）。
