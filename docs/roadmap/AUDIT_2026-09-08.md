## 实测结果（09-08，真实 DeepSeek API + 真实 core 链路，临时库）

脚本 `scripts/_verify_a2b1.py`（`--b1` 只跑 B1，不调 LLM）。

**A2 ✅** —— `agent.handle()` 三轮（xumian 卡）

| 轮 | 输入 | PAD 前 → 后 | last_cause | `_affect_block` 档位 |
|---|---|---|---|---|
| 1 | 今天升职了！哈哈哈哈 | 0.500/0.500 → 0.620/0.600 | happy | 有点起伏（低唤醒档） |
| 2 | 烦死了，项目又延期了 | 0.620/0.600 → 0.528/0.710 | anxious | 被气到/正烦躁 |
| 3 | 睡不着，明天还要汇报 | 0.528/0.710 → 0.445/0.809 | anxious | 被气到/正烦躁 |

跨实例持久化 ✓（重载 `0.445/0.809/anxious`）。顺手修：高唤醒档原按 arousal 单维分档，焦虑场景（v=0.445 a=0.809）拿到「被撩/被气到」措辞，情绪方向是反的 → 按 valence 拆两档。

**B1 ✅** —— 两个出口复测干净

- `prompt_block` → `【你心里挂着的事】「你正在赶毕设改稿」（刚挂上）`

**A1 解释层 ✅** —— `scripts/_verify_p5.py`（xumian 卡，真实 LLM）

三处断点（都是真 bug，不是「功能没实现」）：

1. **触发**：`_reflection_counters` 是内存态（`__init__` 清零），安卓端冷启动频繁 → `persona_candidates_20` 永远攒不到 → 整条 P-5 链从未跑过。改为自上次反思以来的消息数落库（`agent_state.total_messages` + snapshot meta `at_total_messages`），跨重启有效；首跑无快照 → 基准 0 → 立即触发一次。
2. **生成**：`propose_reflection` 纯规则版把置信度最高的记忆原文当 `learned_belief`（实机那几条吐出来的是「用户计划将后端迁移至 hermes 系统」这类**用户事务**，不是角色对关系的理解）→ 加 LLM 版（角色第一人称，`chat_structured`）。注意 `_short_task` 不能用于此：它的出口过 `parse_reply`（对话解析剥结构），拿回来的是台词不是 JSON。
3. **校验**：`validate_reflection` 对角色卡 `taboos`（一整段字符串）做 `for t in taboos` → **遍历字符**，单字「不/我/你」命中一切 → 24 条假冲突把每次反思都毙在 apply 之前。

实测产出：`self_model_chapters` 1 行，`self_interpretation` = 「我对他不只是闲聊的人，是想被接住、被陪着的那一个」；snapshot v2 `at_total_messages=25`；第二次调用被节流挡住（`due=False`）。
