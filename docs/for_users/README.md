# for_users 文档（人读向，按粗细度四档）

同一主题（记忆模块）的四种写法，检查后选定一档推广到其他模块。

| 档 | 文件 | 粒度 | 适合 |
|---|---|---|---|
| A | memory-A-onepager.md | 一页心智模型：五层表+4 步数据流+3 个矛盾自查点 | 快速建立整体图景 |
| B | memory-B-structure.md | 结构地图：组件清单+写入/检索流向图+生命周期不变式+**一致性责任表** | 找结构矛盾（核心推荐） |
| C | memory-C-contracts.md | 功能分区接口契约：写/读/维护/删/周边/迁移六区，只说"保证什么" | 实现时核对越界 |
| D | memory-D-audit.md | 代码对照走查：文件地图+四条走查线+行号+**已实测矛盾标记（⚠）** | 审 PR、核对规范与代码漂移 |

D 档写的时候顺手抓到一个真实漂移：`recall()` docstring 的打分公式（R1_SPEC 旧五项权重）与代码实际（M-A 后八项权重，0.35/0.20/0.15/0.10/0.05×4）不一致——这正是你要的"结构矛盾点"类信息，只有 D 档粒度能承载，A/B/C 装不下。
