# M1 专项细化：Filter 仿生层（docs/M1_SPEC.md）

> 依据：DESIGN.md 4.4（记忆断片）、4.5（社交博弈/打断）、4.9（表达瑕疵）
> **定位锚点**：本项目 = 给予用户真实感的情感陪伴 agent。M1 是「真实感」的底座——
> 让回复不再是「AI 的输出」，而是「一个记得你、会疲惫、会犹豫、会打断你的人的发言」。

---

## 1. 设计原点（为什么需要 Filter 层）

**核心命题**：真实感不来自内容的正确，来自**认知过程的可见性**。

一个真人伴侣的发言是她的记忆状态、情绪状态、精力状态的**外显**：
- 记得清楚 → 说得笃定
- 记不太清 → 说得含糊
- 反复听你说同一件事 → 会忍不住提醒你
- 累了 → 懒得修饰，直接说

Filter 仿生层 = 把「认知状态 → 表达形态」的映射做成显式管线，让 LLM 生成的内容
经过这层滤镜后，**像一个人说的，而不是像一个模型答的**。

**三个子机制，一条数据流**：

```
记忆调度器（确信度）──┐
社交博弈引擎（疲劳/打断）─┼→ 联动仲裁器（状态标签）→ 表达瑕疵选择器 → 输出
```

## 2. 记忆断片（4.4 细化）——「记得」这件事本身要像人

### 2.1 确信度四档（检索时实时折算，不是存储时固定）

| 确信度 | 表达形态 | 真实感依据 |
| --- | --- | --- |
| ≥85% | 自信调用，不加修饰 | 人对自己确信的事不绕弯 |
| 60~84% | 试探性：「我好像记得你提过……是……吗？」 | 人在不确定时用升调求证 |
| 35~59% | 模糊关联 + 抛回：「细节全糊了，你能再跟我说说吗？」 | 人记不清时会**利用对方**补全记忆 |
| <35% | 坦诚遗忘：「你之前说过这事吗？」 | 坦诚遗忘比硬编更有信任感 |

### 2.2 噪声注入（精确度是双刃剑）

- 记忆细节（日期/数字/人名）表达前过模糊化滤镜：「上周三」→「就上次」、「三小时」→「半天」
- **完美精确 = 非人感**。真人回忆必然带模糊，除非是刻骨铭心的事（高确信例外）
- **可逆性**：模糊化不是丢失——用户追问细节时触发重新检索，给出精确值
- **低配实现**：正则替换（`\d+小时` → 好一阵子）；高配：LLM 生成时注入「记忆片段」让模型自然模糊

### 2.3 延迟纠错（真实感的放大器）

- 允许后续「突然想起来」：「等一下，我刚才说错了，不是上个月，是上上个月」
- **真实感依据**：第一次就说对像背稿，纠错才是人脑的运作方式
- 限频：每 N 轮最多 1 次（纠错也是口癖，过量出戏）

### 2.4 断片（长对话后段）

- 长对话后段允许「话到嘴边想不起来」并坦然承认（「哎，刚才想说什么来着……算了」）
- 触发条件：对话轮次 > 阈值 + 低确信记忆被检索

## 3. 打断决策（4.5 细化）——「忍够了」的社交智慧

### 3.1 打断是社交行为，不是系统提示

真人打断有完整的社会逻辑：**先共情，再提醒，给出口，看反应**。

| 复现次数 | 资本余额 | 级别 | 行为 |
| --- | --- | --- | --- |
| 1~2 次 | ≥60% | L0 温和共情 | 正常安抚（人不会在朋友第一次倾诉时就打断） |
| 第 3 次 | 40~60% | L1 轻推 | 「这事你之前说过。不过你有没有想过……」转向解决方案 |
| 第 4 次 | 20~40% | L2 转移 | 「我们聊点别的吧，你上次说那个游戏通关了没？」 |
| ≥5 次 | <20% | L3 直球 | 「这个问题你聊了至少五遍了。你是想听狠话，还是只想让我听着？」 |

### 3.2 三条铁律

1. **角色适配**：打断的表达必须绑定角色性格（温柔学姐委婉提醒 / 毒舌游戏宅副本比喻），否则 OOC——打断方式本身就是人设的一部分
2. **收尾协议**：打断不是终结对话而是**转换频道**——每次打断必须附带「新出口」（方案/新话题/问题），把对话方向盘交回用户
3. **L3 不静默**：L3 后仍响应，但转「工作模式」（极简、就事论事、不投入情绪）——「中场休息」是态度转变不是消失（静默在 QQ 场景会被当成挂了）

### 3.3 自愈回退

- L2/L3 打断后用户负面反馈（极短回复/终止对话）→ 冷却 30 分钟 + 打断阈值提高一级
- **真实感依据**：人被打脸后会识趣——「热脸贴冷屁股后的收敛」

### 3.4 话题复现计数（共享表）

- 同一张 `topic_frequency` 表服务 4.4 复述频率修正与 4.5 打断计数（不重复建设）
- 语义归类：低配 3-gram 指纹 + Jaccard 归并；高配 embedding 聚类（升级路径）

## 4. 表达瑕疵（4.9 细化）——「粗糙」是真实感的底座

### 4.1 核心哲学：瑕疵不是口癖，是认知状态的外显

**「这个人今天状态不错 vs 今天有点累」就是真实感的底座。**

- 高确信 → 流畅精准
- 低确信 → 犹豫模糊
- 高疲劳 → 草率粗糙（疲劳优先级 > 确信度——疲惫的人记清了也会懒得好好说）

### 4.2 双轴映射表（确信度 × 疲劳 → 瑕疵强度）

| 确信度 \ 疲劳 | 正常 | 累 |
| --- | --- | --- |
| 高 | 流畅、标点精准 | 回复变短、换行增多、语法偶尔破碎 |
| 低 | 填充词、细节模糊、「大概三点左右」 | 极简回复（嗯。/知道了。）、刻意错字、不完整句子 |

### 4.3 通道差异化放大器

| 机制 | IM 文字 | TTS 语音 |
| --- | --- | --- |
| 错字与撤回 | 低确信时延迟 0.5~2s 追加「撤回一下，我刚才打错了……」；**限频 15~25%**（过量比口癖更出戏）；仅当回复含具体细节时触发 | — |
| 非语义发声 | — | 「嗯-」「啧」「哎」；动态语速音量（高确信快、低确信慢+降音量） |
| 口癖 | 句尾语气词 + 固定开场（每 2~3 条消息一次形成辨识度）；轻度错字/缩写作为亲密期解锁项 | 填充词（嗯…那个…）——**禁止出现在 IM 通道** |
| 标点 | 低确信时标点退化（句号变空格、连续英文句号「嗯…好吧…。」） | 停顿 `[pause=0.5s]`、词句重复 |

### 4.4 动态衰减（瑕疵不永久）

- 用户提供新信息 / 切到 AI 擅长领域 / 静默 30 分钟 → 瑕疵强度逐级回退（非跳变）
- 回退过程允许「反复」：确信度回升后又短暂回落（「等等，我刚才好像又记错了……」）
- **真实感依据**：人的状态是波动恢复的，不是开关切换

## 5. 数据流总览

```
记忆检索 → 确信度折算（时间衰减×情绪振幅×复述频率）
                  ↓
           联动仲裁器（合并确信度+疲劳+打断级别 → 状态标签）
                  ↓
           表达瑕疵选择器（状态标签 → 瑕疵级别：IM 错字/撤回，TTS 填充/停顿/语速）
                  ↓
           表达渲染层 → 输出（prompt 引导为主，规则后处理为辅）
```

## 6. M1 验收清单（以真实感体验为准，不验收代码结构）

| 项 | 体验级验收 |
| --- | --- |
| 记忆断片 | 用户聊到旧事时，AI 的回答随记忆确信度呈现「笃定 → 试探 → 模糊 → 遗忘」的自然梯度 |
| 噪声注入 | 低确信回忆里不出现精确日期/数字；追问后能给出精确值（可逆） |
| 延迟纠错 | 偶发「等一下，我刚才说错了」——一周对话里出现 1~3 次为自然密度 |
| 打断 L1-L3 | 用户第三次提同一话题时 AI 委婉提醒；第四次自然转移；反复后直球，但始终给「新出口」 |
| 打断自愈 | 用户被打断后冷淡 → 30 分钟内 AI 不再打断，之后更克制 |
| 表达瑕疵 | 低确信/疲劳时回复明显「粗糙」（短句/模糊/撤回），状态恢复后回到流畅——状态可见性 |
| 撤回限频 | 撤回出现率 15~25%，不密集不缺席 |
| 通道隔离 | IM 通道零语音填充词（嗯…那个…）；TTS 通道零「嘛/确实」类文本口癖 |

## 7. 暂缓内容（YAGNI）

- embedding 级精确语义聚类（3-gram 低配够用时不上）
- 撤回的「已撤回」交互样式（QQ 撤回消息 API 暂不接，用文字追加模拟）
- 情绪振幅的实时音频分析（TTS 通道后置，等语音链路成熟）
