# 用户情绪感知（USER_MOOD_SPEC）

状态：v1 定稿（2026-09-11 用户拍板 Q1–Q4 口径，见 §7）。动工前先做 P0 校准（§6）。
定位：本项目 = 给予用户真实感的情感陪伴 agent。本模块 = 她的**输入侧**——
把「用户这条消息是什么情绪」从单轮语义，升级为「相对于你自己的基线，他最近怎么了」。
与 `MIND_LOOP_SPEC` 成对：那一半是她自己的内在生活，这一半是她读你的方式；
两者在 PAD 与表达层汇合，不新增平行管道。

---

## 1. 诊断（现状事实，2026-09-11 代码盘点）

| 已有件 | 事实 |
|---|---|
| 单轮情绪裁决 | 统一判断点（judges）每条消息一次低成本 LLM 调用，产出 `emotion`（happy/sad/angry/anxious）与 `user_state`（含 low_mood） |
| 情绪 → 她的心境 | 判词接进 PAD（09-08），负面情绪让她自己的语气/节奏变化，已实测 |
| 用户文风画像 | style 层持续统计用户消息的长度/表情/疑问比例等慢速基线并持久化（STYLE_LEARNING_SPEC），排除命令/URL 类噪声样本 |
| 裁决留痕 | 有后果的裁决进 `decisions` 账（HARNESS Q3），导出即回放 |

三个缺口（本 spec 的全部增量）：

1. **单条视野**：判断点的输入只有当前消息 + 上一条她的回复（+ 挂心清单）。
   任何「持续几条」的判断无从做起。更关键：极短消息默认不送判（少数含
   场景词的例外）——「嗯」「好」「随便」这种连续短句，整条链路看不见，
   而它正是最典型的异常形态。
2. **基线有数据、无对照**：画像早就存着「他平时写多长、用不用表情」，
   但唯一消费方是回复长度适配——从没有人拿它做「今天不对劲」的对照。
3. **消费断头**：判断点产出的 low_mood 在主通道（安卓）没有消费方——
   就算判准了，行为层也不响应（QQ 侧有自己的 user_state/advisor 消费，不在本次范围）。

## 2. 机制：近况对照

一句话：**规则算偏离，LLM 定性，她软着回应，全程不点破。**

### 2.1 对照层（确定性统计，零 LLM，零新表）

每次送判前，从 messages 表取最近的用户消息窗口（草案：近 6 条、3 小时内的
同一会话），与 style 画像基线对照：

- **主信号**：窗口平均长度 / 基线平均长度 的比值；连续短消息计数
  （明显低于基线的条数）。
- **第二信号（Q1 ②）**：表情 / 感叹号 / 省略号密度相对基线的变化——
  画像里本就统计着这三项，只做**加权**，不设独立触发门槛。

**触发判据（草案值，P0 校准后定稿）**：基线平均长度 ≥ 20 字，且连续 ≥4 条
明显短于基线（低于 50%，或绝对 <6 字）为触发主干；第二信号仅在与主干
同向时增加判定权重（如「连续短句 + 表情密度归零」偏强），反向不触发——
避免「今天不爱用 emoji」这类正常波动单独开闸。同一会话至多触发一次；
画像未成熟（样本不足）时永不触发。

纪律：判据只做「要不要看」的预筛，不做结论；**宁可漏报不可误报**——
她无端「装贴心」比漏检更毁拟真。

### 2.2 裁决层（复用统一判断点，零额外调用）

标记命中时，本轮判断点的送判文本增加三样：

1. 一行对照事实：「他平时消息平均 ~X 字、{表情/标点习惯}；最近 N 条平均 Y 字」；
2. 最近几条消息的原话（窗口内本就短，成本可忽略）；
3. 偏离级字段的说明与取值要求。

同时**临时解除极短消息预筛**（短句本身就是信号，不该被成本预筛挡住）。

LLM 据此定性：是低落/焦虑/烦躁，还是「在打游戏/赶工/赶路」——
后者走既有 busy/away 通道，不误伤。输出**新增一个偏离级字段**
（`user_mood`，闭集 none / mild / low）：`low`＝偏离且负面定性（消费的
唯一触发档）；`mild`＝疑似偏离、证据不足（只留痕）；`none`＝无偏离或
判不出（默认）。字段说明与对照上下文**只在命中时进入送判文本**
（条件注入），解析器常驻兼容——未命中轮次的判断点输入与输出与现状
完全一致，零噪声、零成本。

### 2.3 消费层

| 层 | 行为 | 状态 |
|---|---|---|
| 她的心境 | 判出负面情绪 → PAD → 表达自然变软 | 复用（已有链路，免费） |
| 回复软约束 | 偏离级 = `low` 时，本轮附加一段软约束：别热闹、别追问、**不点破**、回应短一点——形态同现有「场景偏好·忙碌」块 | 新增 |
| 主动织文（Q2 ②） | 主动消息**不挡发**（「随心发言」不变）；织文时把当前用户状态读进素材上下文，语气与素材自然收敛——同「饭点改写带最近消息」的既有做法 | 新增 |
| 当日态（Q3 ②） | 偏离级 = `low` 写入「当日用户状态」，供本日内后续轮次与跨重启连续性使用；按日期自然过期 | 新增 |
| 长期记忆 | v1 不写（机器推断不当事实入库，判词污染是老账）；跨天关心 / 进 digest 挂暂缓 | 不做 |

**当日态**落地形态：共享 `agent_state` 单行上的日期戳状态（日期 + 偏离级 +
一句原因摘要）；写入走**列级 setter 唯一正门**（同 `set_sleep_state` 纪律——
共享单行不做整行 upsert，防跨角色互相覆盖）；读取侧按本地日期判过期
（戳不是今天就当没有）——零定时任务、零清理逻辑。它是回复软约束与
主动织文的状态源，同一日内跨重启、跨会话连续。

### 2.4 铁律

1. **不点破**：任何可见输出（含主动织文）不得出现「检测/分析/注意到你状态」
   类表达。她的变化应表现为语气与节奏，而不是一句「你今天不开心吧」。
2. **fail-open**：对照层数据异常 → 静默退化为现状，绝不阻塞对话。
3. **宁漏勿误**（见 2.1 纪律）。
4. **字段只加这一格**：新增的只有偏离级 `user_mood`（闭集三值）；
   再扩字段需要 A/B 证据。
5. **不进 system 前缀**：对照行只进送判调用与附加块（缓存纪律 + 指令稀释纪律）。

### 2.5 否决的替代方案（为什么不）

- **中文情绪词典/词表直判**：打地鼠（仓内既有案底），语义判断归 LLM。
- **每轮让 LLM 通读窗口**：每轮多付一次调用，且与判断点结论互相打架；
  正解是只在对标命中时给判断点补上下文。
- **阈值直接宣告情绪（不经 LLM）**：长度是弱信号，「打游戏中」与「丧」
  在数字上同形，定性必须看内容。
- **检测汇报式 UI/提示**：与「不点破」铁律冲突，不做。

## 3. 接线图（全复用，不建平行栈）

| 既有 | 接线 |
|---|---|
| 统一判断点（judges） | 送判文本 + 对照上下文（条件注入）；命中时放行极短消息；输出新增偏离级 `user_mood` |
| style 画像（STYLE_LEARNING_SPEC） | 基线只读（不改画像更新规则） |
| messages 表 | 窗口统计唯一数据源 |
| PAD / 心境链路（PERSONA_LOOP / MIND_LOOP） | 判出情绪自动进 PAD，不新增链路 |
| 回复附加块机制 | 软约束注入点（本轮级，不进 system 前缀） |
| 织文调用（待织池） | 命中 / 当日态在场时，素材上下文携带用户状态（不挡发） |
| agent_state 共享单行 | 当日态列（列级 setter 唯一正门，日期戳读侧过期） |
| decisions（HARNESS_SPEC） | 新增一类低频留痕（命中 + 定性 + 偏离级），可回放 |
| QQ advisor | 不在本次范围（QQ 有自己的 user_state 消费，保持不动） |

## 4. 成本与性能

- LLM 调用数不变：命中时仅判断点送判文本小幅增加（对照事实 + 最近原话 +
  字段说明，均条件注入）；未命中零差异。
- 统计在本地单表上即时计算；无新表、无新进程、无后台任务。
- 冷启动不存在「读不懂你还硬读」：画像未成熟 = 静默。

## 5. 验收

1. **P0 离线校准（动工前，无主干改动）**：拿真实导出的 messages 库跑判据——
   输出触发频率与触发样本，人工判读误报；阈值以校准记录为准，
   记录落 `docs/mind/audits/`。
2. **A/B 对照（真实 API）**：三类样本——「连续短句但内容平淡（打工/游戏）」
   「连续短句且内容丧」「正常长句」——对照带/不带对照上下文的判断点输出。
   验收三档：①平淡短句不得判成 `low`（不加恶）②丧类判出率提升
   ③偏离级字段与人工判读一致（Q4 ② 的可测面）。
3. **行为测试（确定性）**：
   - 合成序列：平时 40 字 → 连续 5 条 ≤6 字 ⇒ 命中；基线本就 <15 字 ⇒ 永不命中；
     仅第二信号波动（长度正常、表情异常）⇒ 不命中（不设独立门槛）；
   - 未命中时送判请求体与改造前一致（零噪声）；
   - 命中时对照行在场、极短消息不再被预筛拦；
   - 偏离级闭集：表外值丢弃回 `none`；未命中轮默认 `none`；
   - 偏离级 = `low` ⇒ 软约束块在场（本轮附加块）；`mild` / `none` ⇒ 不在场；
   - 当日态：`low` 写入、跨重启存活、跨日期读侧自动失效、列级 setter
     不整行覆盖（跨角色不互踩）；
   - 输出侧无检测类泄漏词（沿用既有泄漏检查纪律，含织文）；
   - 留痕：命中轮多一条 decisions 记账。
4. **真机 7 天**：`decisions` 里 user_mood 条目可读可解释；抽样「她软下来」
   的轮次能归因到对照 / 当日态记录。

## 6. 分期

- **P0 校准**：离线回放真实消息库定阈值（先行，不碰主干；记录落 `docs/mind/audits/`）。
- **P1 对照层 + 判断点注入**：统计逻辑（含第二信号）+ 条件注入 +
  极短消息放行 + 偏离级字段 + 留痕 + 行为测试。肉眼验收：真机跑几天看 `decisions` 账。
- **P2 消费**：回复软约束块 + 主动织文带状态 + 当日态（写入 / 读侧过期）+
  不点破词面检查。
- **P3**：暂缓清单按触发条件启用。

## 8. 暂缓清单（YAGNI + 触发条件）

- 中文情绪词典扩写：不做。
- 独立的「看窗口判情绪」LLM 调用：不做（与判断点结论会打架）。
- 主动链路的遮断/避让：不做（「随心发言」拍板在先；织文已经收敛语气）。
- 跨天关心（「你昨天怎么了」）：当日态只保当天；跨天连续性挂暂缓
  （等误报率数据 + digest 路线）。
- Q1 第二信号独立门槛、跨日趋势：等 P0/P1 数据。
- per-channel 基线、多模态情绪源（语音/视觉）：没有证据前不做。
- 用户情绪的 UI 展示：不做。
