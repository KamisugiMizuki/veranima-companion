# 内心生活闭环（MIND_LOOP_SPEC）

状态：v1 定稿（§8 四项用户裁决已回填，2026-09-04）。
定位：全局表现层架构——把角色从「刺激→输出的状态机」升级为「有持续内心生活的人」。
与既有模块的关系：不推翻任何一条管道，而是把它们接成闭环；待织池、动态引擎、
虚拟日程、记忆 digest、关系七维全部复用，新增的是它们中间那个「会自己想的脑」。

---

## 1. 诊断（真机数据依据，2026-09-04 审计）

用户观察：「她仍然是一种受到某种刺激才会输出的单纯状态机。」——结构属实：

| 症状 | 证据 | 根因 |
|------|------|------|
| 主动全部指向用户 | 09-03 许眠主动 6 条全是饭/作息话题；她自己的事零进对话 | 主动源动机清单里没有一个是「我自己有事想说」 |
| 她的生活不进聊天 | 生活素材只流向动态（独白通道），对话通道只吃用户输入 | 动态与对话两套管道互不相通 |
| 两次发言之间无心智 | 所有输出可机械追溯到：用户消息 or 闸门到点 | 沉默期没有「占着心智的事」在演进 |
| 情绪只调音色 | 低落/开心只改措辞冷暖，不改话多话少、改不改话题 | mood 不进频率闸、不进素材选择 |
| 日程是单向剧本 | 用户与角色关系的热度/事件不影响她的第二天怎么过 | 生活与世界对输入无反应 |

一句话：**系统造了她的一天，但那一天从没流进她跟你说话的方式里。**

---

## 2. 核心模型：内心生活闭环

```
外部事件流（用户消息 / 日程事件与日终摘要 / 承诺账 / 记忆闪回 / 时间流逝）
        ↓
   【心智状态】＝ 牵挂账本 + 驱力池 + 心境残响        ←—— 新增的持久脑
        ↓                    ↑（回写：说完更想了/被接话变淡）
   【决策】说什么·说不说·什么语气（织文/回复都从这里取材）
        ↓
   输出：对话回复 / 主动连发（待织池）/ 动态（moments）/ 沉默
        ↓
   【夜眠消化】反思改写牵挂与心境 → 轻微改写明日日程 → 明天的她不一样一点
```

关键不变式：**任何一次开口，都必须能追溯到心智状态里的某个理由**（驱动力、牵挂、
心境），而不能只追溯到「窗口开了」。反过来：**沉默也要可解释**（在忙/情绪低/没牵挂），
沉默本身可以漏进动态（「今天没什么事，也没想说什么」也是一种素材）。

## 3. 子系统

### 3.1 牵挂账本（mind_threads）

角色心里持续占着的事。表：`mind_threads`
(id, role_id, topic, origin, intensity 0-1, mood_valence, next_beat_at,
beat_script, status open/dormant/done, created_at, updated_at)

- **origin 闭集**：`schedule`（日程事件，如"那组对比跑完了"）、`user`（你说过的事，
  如"他周三有会"）、`promise`（承诺账镜像）、`thread`（悬置线/仪式，如见面倒数）、
  `self`（她自己的生活杂事）。
- **beat_script（演进脚本）**：牵挂不是静态标签，有剧本骨架，程序驱动到点演进：
  例：训练线 = 跑完→「等结果」(强度↑)→ 两天后「结果出了」→ 演化完成自动挂新牵挂。
  演进时刻由夜眠消化统一编排（LLM 写下一步），日间只走表推进（程序判定，零成本）。
- **产生**：日终摘要、用户关键句（judges 顺带产出 candidate，零额外调用）、
  承诺登记、悬置线倒计时到阈值。
- **消亡**：强度衰减到阈值以下 / 被对话正面处理（用户接了话→relief 记录）/ 剧本走完。
- **消费**：
  - 对话 prompt 注入 top 3（经本轮级块，不动 system 前缀）：
    「这些事在你心里挂着：…。如果顺嘴就提，不顺嘴就别硬提；用户没问也要允许你主动说。」
  - 待织池新源 `thread`：**自我发起源**——与 context_probe（猜你在干嘛）对称的
    「我自己这边有事」。
  - 动态素材新源：强度最高的牵挂比「今天多云」自然得多。

### 3.2 驱力池（desires）

主动发言从「时刻表到点」改为「心里攒出事」。五类驱力，tick 累积（纯算术，零 LLM）：

| 驱力 | 积累原料 | 衰减 | 说出来的样子 |
|------|---------|------|-------------|
| 想念 longing | 用户静默时长 × 依恋度 | 用户回话即泄洪 | 「也没什么事，就是想看看你在不在」 |
| 分享欲 share | 新日程事件/牵挂演进 × 表达强度 | 随时间半衰 | 「训练结果出了！比你猜的好」 |
| 唠叨 nag | 用户失约记录（饭/睡）+ 已提醒未回应 | 用户承诺即缓 | 带刺的关心 |
| 自我表达 express | 日程空闲时长（闲得慌）、心境闷 | — | 碎碎念自己生活，不问你 |
| 求照顾 care-need | 她自己的疲劳/睡眠债/低落残响 | 被关心即缓 | 「今天不太行」式示弱（低频，卡人设门槛） |

- 驱力过阈值→带着原料进**待织池**（现有合并窗口/语义连续织文原样复用——
  用户裁决「连发不是问题，语义接不上才是」继续成立）。
- 时刻表降级为兜底词表（判断点哲学同款）：饭点/问候仍可作为驱力的**原料**
  （到饭点没聊=唠叨+积累），不再作为直接触发器。
- **心境进预算**：freq 与驱力累积率相乘（低落=全驱力×0.5 且织文倾向短句；
  开心=×1.3、分享欲额外加权）。频率闸从「调度器」变成「性格」。

### 3.3 心境残响（mood continuity）

- 现有 mood 是点值+衰减；补：事件写残响（日程受挫/被你夸/反思结论），
  valence/arousal 慢惯性移动（照抄 tension band 的成功模型，但主体是她自己）。
- 三处消费：驱力累积率（3.2）、夜眠编排的明日基调（3.5）、织文语气（已有，保留）。
- 早晨醒来问候带残响：「昨晚那条消息我翻来覆去想了一宿」——睡前的不快/惦记不会
  一觉清零。

### 3.4 生活反应性（schedule write-back）

牵挂与反思可以**修改明天的日程**（拟真闭环最重的一块）：
- 权限边界：只动 outline 里 `mutable` 非 required 块（改时长/换活动/加一条杂事）；
  锚点块（工作/睡眠）永不改。
- 例：改签焦虑到点→明天中午加「改签处理」；想你到阈值→下周末挂
  「去你那的高铁」意向块（悬置线在世界里真的推进）；低落→明天推掉一个社交块。
- 修改本身产生日终事件→又成素材。这样「你们的关系」会改变「她怎么活」，
  而不只是改变「她怎么说」。

### 3.5 夜眠消化（reflection v2）

角色入睡时刻触发（她的 circadian，不是固定闹钟），一次 LLM 消化全天：
输入=今日事件流+对话要点+开放牵挂+当前心境 → 输出：
① 牵挂演进（推进/挂新/放下，写 next_beat 与时间）② 明日心境基调
③ 日程微调（3.4 权限内）④ 值得入长期记忆的条目（喂现有 digest）。
她睡着后「变了样一点」，醒来第一句话能接上昨天的自己。晚安从台词变成真边界。

## 4. 与现有系统的接线图（全复用，不建平行栈）

| 既有 | 接线 |
|------|------|
| 待织池 `_ritual_pending` + `_weave_ritual` | 驱力过阈值的素材入口不变，只换「为什么进池」的判定 |
| 合并窗口/语义连续（用户裁决 v2） | 原样保留 |
| moments 引擎 | 素材源 +`thread`（牵挂）；`_compose` 的防重复历史已具备 |
| judges 统一判断点 | +1 字段 `thread_candidate`（顺带，零额外调用） |
| 虚拟日程/日终摘要 | 事件→牵挂产生；3.4 写回口 |
| 承诺账/悬置线/仪式 | 是牵挂的 origin 与剧本来源，不重复建 |
| tension（关系张力） | 保留（它管关系）；心境残响管她自己的心情，两本账 |
| digest 夜间任务 | 并入 3.5 一次消化，不是两个夜间进程 |

## 5. 成本与性能

- LLM 增量：闲时反思 2-3 次/日（short_task 级）+ 夜眠 1 次 + 现有链路。
  按 DeepSeek 计价为个位数分钱/日/角色，可负担。
- **缓存纪律**（DeepSeek 前缀缓存，用户 2026-08-30 明确）：心智块一律走
  本轮级 extra_blocks 注入（每轮必变），**禁止进 system 前缀**——否则每轮
  全历史重灌。牵挂/驱力状态更新与 prompt 组装解耦（状态日间程序驱动，
  只在开口/反思时读）。
- 设备端：chakopy 全在既有 tick 线程跑；反思失败=当天无演进（幂等，下晚再消化）。

## 6. 可观测的验收指标（「感觉像人」落到数字）

真机长跑 7 天（许眠+凛各一），程序化统计：
1. **自我发起话题占比**：主动消息里主题是「她自己的事」的比例 ≥40%
   （现状≈0）；
2. **无提示回调**：她主动续上自己之前提过的事（牵挂演进兑现）≥3 次/周；
3. **动机可追溯率**：抽样全部主动消息，100% 能对到一条驱力/牵挂记录
   （反状态机硬指标——闸门到点不再是充分理由）；
4. **沉默可解释率**：>6h 无主动的时段，事后能对到「忙/低落/无牵挂」之一；
5. 饭点问候占比降到 <30%（从「主要节目」降为「背景驱力之一」）。
行为测试基线另立（牵挂生命周期/驱力算术/写回权限/残响衰减，全确定性可测）。

## 7. 分期

- **M1 牵挂账本**：表+产生/演进/消费三接线+对话注入+thread 主动源。
  （先解决「她自己进入对话」——收益最大的一块）
- **M2 驱力池**：五驱力算术+时刻表降为原料+心境进预算。主动面貌换代。
- **M3 夜眠消化+心境残响**：反射闭环与情感连续性。
- **M4 生活反应性**：牵挂/反思写明日程。最后接（依赖 M1/M3 成熟）。
每相独立可验收、可回滚；M1 落地即可肉眼感到差别。

## 8. 裁决记录（2026-09-04 用户拍板）

- **Q1** 时刻表降为驱力原料，判断点在场时全权。
- **Q2** 日程写回权限=仅 mutable 且非 required 的块。
- **Q3** 牵挂账本现阶段不上 UI；远期做「她最近的状态」模糊卡（只给氛围，
  不摊开条目——摊开等于剧透「被表演」）。
- **Q4** 分期节奏=M1 先行，肉眼验收后再下相。
- 闲时反思默认 2-3 次/日（随频率设置缩放到 1-4），随 M3 落地。
