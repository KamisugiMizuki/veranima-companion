## 4. 定稿阈值（回填 §2.1）

1. **基线 = 最近 50 条本角色用户消息长度的中位数**（稳健中心）。不用均值——真机均值被长文拉到 30.6 而中位只有 12，均值口径会把 12 字的正常消息算成「短」。
2. **短句 = 字数 < 6，或不高于基线 50%**。
3. **触发 = 连续 ≥4 条短句，且其中 ≥2 条文本不同**；**相邻重复内容不计入连发**（同一条消息重发=重试/测试，不是「连着几句没力气」）。
4. **基线样本 <20 条不触发**（画像未成熟）。
5. **同一会话至多触发一次**（会话=用户消息间隔 ≤3h 连续段）。
6. 第二信号（表情/标点密度）**只加权、不独立触发**；反向不触发。

- **架构结论**：长度类信号无法把「低落」与「测试连发/场景短句」分开——含噪是结构性的。所以预筛只回答「要不要让判断点多看一眼」，定性归判断点；命中才注入对照上下文，判 `none` 就没有任何副作用。这条与「宁可漏报不可误报」一致。
